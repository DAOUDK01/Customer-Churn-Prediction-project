# 🎯 Customer Churn Prediction Demo UI

## Overview

This Streamlit application provides a **minimal demonstration interface** for the production Customer Churn Prediction API. It contains **NO ML logic** - all predictions are made by calling the existing FastAPI backend.

## Features

### Single Customer Prediction
- Simple form interface for individual customer data entry
- Real-time prediction results with risk level and probability
- Business impact summary (revenue at risk, intervention recommendations)
- Quick preset buttons for common customer profiles

### Batch Processing
- CSV file upload for multiple customers
- Batch prediction processing (up to 100 customers in demo)
- Summary statistics and detailed results table
- Sample CSV download template

## Requirements

```bash
pip install streamlit requests pandas
```

## How to Run

### 1. Start the API Server (Required)
```bash
# In terminal 1: Start the production API
cd customer-churn-ml
python src/api.py
```

The API will start on `http://localhost:8000`

### 2. Start the Demo UI
```bash
# In terminal 2: Start the Streamlit UI
cd customer-churn-ml
streamlit run streamlit_app.py
```

The UI will open automatically in your browser at `http://localhost:8501`

## Usage Instructions

### Single Customer Mode
1. Select "Single Customer" in the sidebar
2. Enter customer details:
   - **Tenure**: How long customer has been with company (months)
   - **Monthly Charges**: Customer's monthly bill ($)
   - **Total Charges**: Total amount customer has paid ($)
3. Click "🔮 Predict Churn Risk"
4. View results showing risk level, probability, and business impact

### Batch Processing Mode
1. Select "Batch Processing" in the sidebar
2. Download sample CSV template (optional)
3. Upload your customer CSV file with required columns:
   - `tenure`
   - `MonthlyCharges` 
   - `TotalCharges`
4. Click "🚀 Process Batch Predictions"
5. View summary statistics and detailed results

## Sample Customer Profiles

The UI includes quick preset buttons for testing:

- **High Value Customer**: Long tenure, high charges (typically low risk)
- **New Customer**: Short tenure, high charges (typically high risk)

## Error Handling

- **API Not Running**: Clear instructions to start the backend API
- **Invalid Data**: Validation messages for missing columns or bad format
- **Connection Issues**: Helpful error messages for network problems

## Technical Notes

- **No ML Logic**: All predictions come from the production API
- **Demo Limits**: Batch processing limited to 100 customers for performance
- **Authentication**: Uses the demo token configured in the API
- **Timeout**: 10 seconds for single predictions, 30 seconds for batch

## API Health Check

The UI automatically checks if the API server is running and displays connection status. If the API is down, clear instructions are provided to start it.

## Troubleshooting

### "API Server Not Running" Error
1. Ensure you're in the `customer-churn-ml` directory
2. Start the API with: `python src/api.py`
3. Wait for "Uvicorn running on http://localhost:8000" message
4. Refresh the Streamlit page

### CSV Upload Issues
1. Ensure CSV has required columns: `tenure`, `MonthlyCharges`, `TotalCharges`
2. Check for proper numeric data (no text in number fields)
3. Download and use the provided sample template

### Connection Errors
1. Verify API is running on port 8000
2. Check firewall settings
3. Ensure no other applications are using the ports

## Demo Limitations

This UI is designed for **demonstration purposes only**:

- No authentication flow (uses hardcoded demo token)
